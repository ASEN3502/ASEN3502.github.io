\textbf{Dormand--Prince RK5(4)} (used by \texttt{ode45}) for $y' = f(t, y)$, step $h$:
\begin{align*}
  k_1 &= f\bigl(t_n,\; y_n\bigr) \\
  k_2 &= f\bigl(t_n + \tfrac{1}{5}h,\; y_n + h\,\tfrac{1}{5}k_1\bigr) \\
  k_3 &= f\bigl(t_n + \tfrac{3}{10}h,\; y_n + h\bigl(\tfrac{3}{40}k_1 + \tfrac{9}{40}k_2\bigr)\bigr) \\
  k_4 &= f\bigl(t_n + \tfrac{4}{5}h,\; y_n + h\bigl(\tfrac{44}{45}k_1 - \tfrac{56}{15}k_2 + \tfrac{32}{9}k_3\bigr)\bigr) \\
  k_5 &= f\bigl(t_n + \tfrac{8}{9}h,\; y_n + h\bigl(\tfrac{19372}{6561}k_1 - \tfrac{25360}{2187}k_2 + \tfrac{64448}{6561}k_3 - \tfrac{212}{729}k_4\bigr)\bigr) \\
  k_6 &= f\bigl(t_n + h,\; y_n + h\bigl(\tfrac{9017}{3168}k_1 - \tfrac{355}{33}k_2 + \tfrac{46732}{5247}k_3 + \tfrac{49}{176}k_4 - \tfrac{5103}{18656}k_5\bigr)\bigr) \\
  k_7 &= f\bigl(t_n + h,\; y_n + h\bigl(\tfrac{35}{384}k_1 + \tfrac{500}{1113}k_3 + \tfrac{125}{192}k_4 - \tfrac{2187}{6784}k_5 + \tfrac{11}{84}k_6\bigr)\bigr)
\end{align*}
Fifth-order step (the one that is kept):
\[
  y_{n+1} = y_n + h\Bigl(\tfrac{35}{384}k_1 + \tfrac{500}{1113}k_3 + \tfrac{125}{192}k_4 - \tfrac{2187}{6784}k_5 + \tfrac{11}{84}k_6\Bigr)
\]
Fourth-order check:
\[
  \hat{y}_{n+1} = y_n + h\Bigl(\tfrac{5179}{57600}k_1 + \tfrac{7571}{16695}k_3 + \tfrac{393}{640}k_4 - \tfrac{92097}{339200}k_5 + \tfrac{187}{2100}k_6 + \tfrac{1}{40}k_7\Bigr)
\]
Error estimate used to pick the next step size:
\[
  \text{err} = \lVert y_{n+1} - \hat{y}_{n+1} \rVert = O(h^5),
  \qquad
  h_{\text{new}} = h \left(\frac{\text{tol}}{\text{err}}\right)^{1/5}
\]
Note $k_7$ uses the fifth-order result, so it equals $k_1$ of the next step (``first same as last'').

# Optimization: Penalties and Lagrange Multipliers

  <p>The problem is one-dimensional so that everything can be drawn:</p>
  \[ \begin{aligned}
     \underset{x}{\text{minimize}} &\quad f(x) = x^2 \\
     \text{subject to} &\quad g(x) = 1 - x \le 0 .
     \end{aligned} \]
  <p>The constraint \(x \ge 1\) is written as \(g(x) \le 0\), the convention
  in the <a href="https://mdobook.github.io/html/constrained/">MDO book</a>.
  The unconstrained minimum \(x = 0\) is infeasible (shaded), so the
  constrained optimum sits on the boundary, \(x^* = 1\), where the constraint
  is <em>active</em>. Every method below turns this into an unconstrained
  problem whose minimizer is marked with a dot; the goal is to see how that
  dot approaches \(x^*\) as the parameter changes.</p>

  <h2>Exterior Penalty</h2>

  <p>Add a quadratic penalty that is zero when the constraint is satisfied and
  grows with the violation,</p>
  \[ \hat f(x;\mu) = f(x) + \frac{\mu}{2}\,\max\!\big(0,\, g(x)\big)^2 , \]
  <p>and minimize \(\hat f\) instead. Since the penalty only turns on
  <em>outside</em> the feasible region, the minimizer is always slightly
  infeasible: here \(2x - \mu(1-x) = 0\) gives
  \(x = \mu/(2+\mu) < 1\). The penalty parameter is increased
  between solves, \(\mu_{k+1} = \rho\,\mu_k\) with \(\rho > 1\), and the
  minimizer approaches \(x^*\) only as \(\mu \to \infty\), at which point
  \(\hat f\) has a sharp kink and is badly conditioned.</p>

  <h2>Interior Penalty (Logarithmic Barrier)</h2>

  <p>Instead, add a penalty that is finite inside the feasible region and
  blows up at the boundary,</p>
  \[ \hat f(x;\mu) = f(x) - \mu \ln\!\big(-g(x)\big) , \]
  <p>which is only defined for \(g(x) < 0\), so the iterates can never leave
  the feasible region (hence <em>barrier</em>). The minimizer is always
  strictly feasible: \(2x - \mu/(x-1) = 0\) gives
  \(x = \tfrac{1}{2}\big(1 + \sqrt{1 + 2\mu}\big) > 1\). Here \(\mu\) is
  <em>decreased</em> between solves, \(\mu_{k+1} = \rho\,\mu_k\) with
  \(\rho < 1\), and the minimizer approaches \(x^*\) as \(\mu \to 0\).
  The starting point must be feasible.</p>

  <h2>Lagrange Multipliers</h2>

  <p>Rather than approximating the constraint with a penalty, form the
  Lagrangian with a multiplier \(\sigma\) for the inequality constraint,</p>
  \[ \mathcal{L}(x, \sigma) = f(x) + \sigma\, g(x) = x^2 + \sigma (1 - x) . \]
  <p>For a fixed \(\sigma\), \(\mathcal{L}\) is an unconstrained function of
  \(x\) whose stationary point is where \(\nabla f + \sigma \nabla g = 0\),
  i.e. \(2x - \sigma = 0\), so \(x = \sigma/2\). The
  Karush&ndash;Kuhn&ndash;Tucker (KKT) conditions say the right \(\sigma\)
  is the one that makes this stationary point feasible with the constraint
  either inactive (\(\sigma = 0\)) or active (\(g = 0\)):</p>
  \[ \nabla f + \sigma \nabla g = 0, \qquad g \le 0, \qquad
     \sigma\, g = 0, \qquad \sigma \ge 0 . \]
  <p>Drag \(\sigma\) and watch the stationary point of \(\mathcal{L}\) slide
  along the parabola. Only at \(\sigma^* = 2\) does it land on the boundary
  \(g = 0\); for smaller \(\sigma\) it is infeasible and for larger it is
  feasible but \(\sigma g \neq 0\). The multiplier is the sensitivity of the
  optimum to the constraint: relaxing it to \(x \ge 1 - \delta\) would
  reduce \(f^*\) by about \(\sigma^* \delta\).</p>

  <div class="op-controls">

      <input type="range" id="op-ls" min="0" max="4" step="0.05" value="1"></label>
  </div>

  <p>Unlike the penalty methods, the Lagrangian gives the exact optimum with no
  limit to take, but it trades the problem of finding \(x\) for the problem
  of finding \(\sigma\) (and, with several constraints, deciding which are
  active). Methods such as sequential quadratic programming solve the KKT
  conditions for \(x\) and \(\sigma\) together.</p>

<script>
(function () {
  function $(id) { return document.getElementById(id); }
  function fmt(v, d) { return isFinite(v) ? v.toFixed(d) : 'NaN'; }
  var PLOTOPTS = { displayModeBar: false, responsive: true };
  var XL = -1.5, XR = 3, YT = 8, N = 601;
  var xs = []; for (var i = 0; i < N; i++) xs.push(XL + (XR - XL) * i / (N - 1));
  function f(x) { return x * x; }
  function g(x) { return 1 - x; }
  var FY = xs.map(f);

  // Shared figure: f, the infeasible region, x* = 1, plus a method-specific curve and its minimizer.
  // ghosts: [{label, fn}] faint copies of the curve at other parameter values
  function draw(div, curveName, curveFn, xmin, color, ghosts, extra) {
    var ys = xs.map(curveFn);
    var traces = (ghosts || []).map(function (gh, i) {
      return { type: 'scatter', mode: 'lines', x: xs, y: xs.map(gh.fn), line: { color: color, width: 1 },
               opacity: 0.3, name: 'other values', legendgroup: 'ghost', showlegend: i === 0,
               connectgaps: false, hovertemplate: gh.label + '<br>x %{x:.2f}<br>%{y:.2f}<extra></extra>' };
    }).concat([
      { type: 'scatter', mode: 'lines', x: xs, y: FY, line: { color: '#123f63', width: 2 },
        name: 'f(x) = x²', hovertemplate: 'x %{x:.2f}<br>f %{y:.2f}<extra></extra>' },
      { type: 'scatter', mode: 'lines', x: xs, y: ys, line: { color: color, width: 2.5 },
        name: curveName, connectgaps: false, hovertemplate: 'x %{x:.2f}<br>%{y:.2f}<extra></extra>' },
      { type: 'scatter', mode: 'markers', x: [xmin], y: [curveFn(xmin)], showlegend: false,
        marker: { size: 12, color: color, line: { color: '#fff', width: 1.5 } }, hoverinfo: 'skip' },
      { type: 'scatter', mode: 'markers', x: [1], y: [1], name: 'x* = 1', hoverinfo: 'skip',
        marker: { size: 10, color: '#2a7a3b', symbol: 'star' } }
    ], extra || []);
    var layout = {
      margin: { l: 45, r: 10, t: 10, b: 40 }, paper_bgcolor: 'rgba(0,0,0,0)',
      xaxis: { title: 'x', range: [XL, XR], zeroline: false },
      yaxis: { range: [-1, YT], zeroline: true },
      legend: { x: 0.02, y: 0.98 },
      shapes: [
        { type: 'rect', x0: XL, x1: 1, y0: -1, y1: YT, fillcolor: 'rgba(192,42,42,.10)', line: { width: 0 }, layer: 'below' },
        { type: 'line', x0: 1, x1: 1, y0: -1, y1: YT, line: { color: '#c02a2a', width: 1.5, dash: 'dash' } },
        { type: 'line', x0: xmin, x1: xmin, y0: -1, y1: curveFn(xmin), line: { color: color, width: 1, dash: 'dot' } }
      ],
      annotations: [{ x: (XL + 1) / 2, y: YT - 0.3, text: 'infeasible, g(x) > 0', showarrow: false, font: { color: '#c02a2a' } }]
    };
    Plotly.react(div, traces, layout, PLOTOPTS);
  }

  // ---- exterior penalty --------------------------------------------------
  function drawExt() {
    var mu = Math.pow(10, +$('op-em').value);
    $('op-emv').textContent = mu >= 100 ? fmt(mu, 0) : mu >= 10 ? fmt(mu, 1) : fmt(mu, 2);
    var fh = function (x) { return f(x) + 0.5 * mu * Math.pow(Math.max(0, g(x)), 2); };
    var xm = mu / (2 + mu);
    var ghosts = [0.1, 0.3, 1, 3, 10, 30, 100, 300, 1000].map(function (m) {
      return { label: 'μ = ' + m, fn: function (x) { return f(x) + 0.5 * m * Math.pow(Math.max(0, g(x)), 2); } };
    });
    draw('op-eplot', 'f̂(x; μ) = f + (μ/2) max(0, g)²', fh, xm, '#b06a00', ghosts);
    $('op-enote').innerHTML = 'minimizer of f̂: x = μ/(2+μ) = <b>' + fmt(xm, 4) + '</b>, ' +
      'g(x) = <b>' + fmt(g(xm), 4) + '</b> <span class="op-bad">(infeasible)</span>, ' +
      'f(x) = <b>' + fmt(f(xm), 4) + '</b> vs f* = 1. Increase μ to push it toward x*.';
  }
  $('op-em').addEventListener('input', drawExt);

  // ---- interior penalty --------------------------------------------------
  function drawInt() {
    var mu = Math.pow(10, +$('op-im').value);
    $('op-imv').textContent = mu >= 1 ? fmt(mu, 2) : mu >= 0.01 ? fmt(mu, 3) : fmt(mu, 4);
    var fh = function (x) { return x > 1 ? f(x) - mu * Math.log(-g(x)) : null; };
    var xm = 0.5 * (1 + Math.sqrt(1 + 2 * mu));
    var ghosts = [10, 3, 1, 0.3, 0.1, 0.03, 0.01, 0.003, 0.001].map(function (m) {
      return { label: 'μ = ' + m, fn: function (x) { return x > 1 ? f(x) - m * Math.log(-g(x)) : null; } };
    });
    draw('op-iplot', 'f̂(x; μ) = f − μ ln(−g)', fh, xm, '#7b3fa0', ghosts);
    $('op-inote').innerHTML = 'minimizer of f̂: x = ½(1 + √(1 + 2μ)) = <b>' + fmt(xm, 4) + '</b>, ' +
      'g(x) = <b>' + fmt(g(xm), 4) + '</b> <span class="op-good">(feasible)</span>, ' +
      'f(x) = <b>' + fmt(f(xm), 4) + '</b> vs f* = 1. Decrease μ to pull it toward x*.';
  }
  $('op-im').addEventListener('input', drawInt);

  // ---- Lagrangian ----------------------------------------------------------
  function drawLag() {
    var s = +$('op-ls').value;
    $('op-lsv').textContent = fmt(s, 2);
    var L = function (x) { return f(x) + s * g(x); };
    var xm = s / 2;
    var ghosts = [0, 0.5, 1, 1.5, 2, 2.5, 3, 3.5, 4].map(function (sg) {
      return { label: 'σ = ' + sg, fn: function (x) { return f(x) + sg * g(x); } };
    });
    draw('op-lplot', 'ℒ(x, σ) = f + σ g', L, xm, '#2a7a3b', ghosts, [
      { type: 'scatter', mode: 'markers', x: [xm], y: [f(xm)], name: 'f at stationary point', hoverinfo: 'skip',
        marker: { size: 9, color: '#123f63', symbol: 'circle-open', line: { width: 2 } } }
    ]);
    var gx = g(xm), status;
    if (Math.abs(gx) < 1e-9)      status = '<span class="op-good">g = 0 and σ ≥ 0: KKT satisfied, x = x*</span>';
    else if (gx > 0)              status = '<span class="op-bad">g &gt; 0: infeasible</span>';
    else                          status = '<span class="op-bad">g &lt; 0 but σ &gt; 0, so σ g ≠ 0: not KKT</span>';
    $('op-lnote').innerHTML = 'stationary point of ℒ: x = σ/2 = <b>' + fmt(xm, 3) + '</b>, ' +
      'g(x) = <b>' + fmt(gx, 3) + '</b>, σ g = <b>' + fmt(s * gx, 3) + '</b>. ' + status + '.';
  }
  $('op-ls').addEventListener('input', drawLag);

  drawExt(); drawInt(); drawLag();
})();
</script>

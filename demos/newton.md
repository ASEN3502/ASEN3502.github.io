  <h2>The Methods</h2>

  <p>All three methods pick a search direction \(\vec{p}_k\) and then step
  along it, \(\vec{x}_{k+1} = \vec{x}_k + \alpha_k\, \vec{p}_k\). They differ
  in the direction:</p>
  <ul>
    <li><b style="color:var(--op-pur)">Steepest descent</b> uses
      \(\vec{p}_k = -\nabla f(\vec{x}_k)\).</li>
    <li><b style="color:var(--op-grn)">Conjugate gradient</b> (Polak&ndash;Ribi&egrave;re+)
      bends the new direction with the previous one,
      \(\vec{p}_k = -\nabla f_k + \beta_k\, \vec{p}_{k-1}\), with
      \(\beta_k = \max\!\left(0,\; \dfrac{\nabla f_k^\mathsf{T}(\nabla f_k - \nabla f_{k-1})}
                                         {\nabla f_{k-1}^\mathsf{T} \nabla f_{k-1}}\right)\).</li>
    <li><b style="color:var(--op-amb)">Newton</b> fits a quadratic to \(f\)
      at \(\vec{x}_k\) using the gradient and Hessian,
      \[ q(\vec{x}) = f_k + \nabla f_k^\mathsf{T}(\vec{x} - \vec{x}_k)
          + \tfrac{1}{2}(\vec{x} - \vec{x}_k)^\mathsf{T} H_k (\vec{x} - \vec{x}_k), \]
      and jumps to its stationary point: \(H_k \vec{p}_k = -\nabla f_k\)
      with \(\alpha_k = 1\).</li>
  </ul>
  <p>The step size \(\alpha_k\) can be chosen three ways. <i>Fixed</i>
  uses the slider's \(\alpha\) every time. <i>Exact line search</i>
  minimizes \(f\) along \(\vec{p}_k\) with the bracketing and
  golden-section search from the previous lecture, starting the bracket at
  the slider's \(\alpha\). <i>Armijo backtracking</i> starts from the
  slider's \(\alpha\) and halves it (\(\rho = 0.5\)) until the
  sufficient decrease condition
  \[ f(\vec{x}_k + \alpha\, \vec{p}_k) \le f(\vec{x}_k)
       + \mu_1\, \alpha\, \nabla f_k^\mathsf{T} \vec{p}_k,
     \qquad \mu_1 = 10^{-4}, \]
  holds. Newton ignores the slider: its natural step is \(\alpha = 1\),
  which it uses as the fixed step and as the starting point for either line
  search. If the Newton direction is not a descent direction (the Hessian is
  not positive definite), the line-search versions fall back to a steepest
  descent step.</p>

  <p id="op-fndesc"></p>

  <p>On the quadratic, Newton lands on the minimum in a single step because
  the fitted quadratic <em>is</em> the function. Conjugate gradient with an
  exact line search needs only two steps (one per dimension); with Armijo
  backtracking the directions are no longer conjugate and it takes more, but
  it still avoids the zig-zag of steepest descent. On Rosenbrock the banana valley is curved, so no quadratic fits
  for long, but Newton still follows the valley far faster than the gradient
  methods. Himmelblau's function has four minima, a local maximum, and four
  saddles. Newton jumps to the stationary point of its quadratic model,
  whichever kind it is, so from a start where the Hessian is not positive
  definite it can converge happily to a maximum or saddle. Turn on the fitted
  quadratic and watch what it is aiming at.</p>

(function () {
  function $(id) { return document.getElementById(id); }
  function fmt(v, d) { return isFinite(v) ? v.toFixed(d) : 'NaN'; }
  var PLOTOPTS = { displayModeBar: false, responsive: true };
  var COL = { sd: '#7b3fa0', cg: '#2a7a3b', nt: '#b06a00' };
  var NAME = { sd: 'steepest descent', cg: 'conjugate gradient', nt: 'Newton' };

  // ---- test functions: f, gradient, Hessian ------------------------------
  var QR = 8, QTH = Math.PI / 6, qc = Math.cos(QTH), qs = Math.sin(QTH);
  var QA = qc * qc + QR * qs * qs, QB = qc * qs * (1 - QR), QD = qs * qs + QR * qc * qc;
  var FUNCS = {
    quad: {
      desc: 'The quadratic is \\(f = \\tfrac12 \\vec{x}^\\mathsf{T} A \\vec{x}\\) with eigenvalues 1 and ' + QR +
            ' (condition number ' + QR + ') and principal axes rotated 30&deg;; its minimum is at the origin.',
      box: [-3, 3, -3, 3], tf: function (v) { return v >= 0 ? Math.sqrt(v) : null; },   // levels evenly spaced in radius
      f: function (x, y) { return 0.5 * (QA * x * x + 2 * QB * x * y + QD * y * y); },
      g: function (x, y) { return [QA * x + QB * y, QB * x + QD * y]; },
      h: function (x, y) { return [QA, QB, QD]; }
    },
    rosen: {
      desc: 'Rosenbrock\'s function is \\(f = (1-x)^2 + 100\\,(y - x^2)^2\\), with its only minimum at (1, 1) ' +

      box: [-2, 2, -1, 3], tf: function (v) { return v + 0.1 > 0 ? Math.log10(v + 0.1) : null; },
      f: function (x, y) { var u = 1 - x, v = y - x * x; return u * u + 100 * v * v; },
      g: function (x, y) { var v = y - x * x; return [-2 * (1 - x) - 400 * x * v, 200 * v]; },
      h: function (x, y) { return [2 - 400 * y + 1200 * x * x, -400 * x, 200]; }
    },
    himmel: {
      desc: 'Himmelblau\'s function is \\(f = (x^2 + y - 11)^2 + (x + y^2 - 7)^2\\). It has four minima where ' +
            '\\(f = 0\\), a local maximum near (&minus;0.27, &minus;0.92), and four saddle points between the minima. ' +
            'Contours are drawn at logarithmically spaced levels.',
      box: [-5, 5, -5, 5], tf: function (v) { return v + 0.1 > 0 ? Math.log10(v + 0.1) : null; },
      f: function (x, y) { var u = x * x + y - 11, v = x + y * y - 7; return u * u + v * v; },
      g: function (x, y) { var u = x * x + y - 11, v = x + y * y - 7; return [4 * x * u + 2 * v, 2 * u + 4 * y * v]; },

  function curFunc() { return FUNCS[document.querySelector('input[name=op-fn]:checked').value]; }
  function lsMode() { return document.querySelector('input[name=op-ls]:checked').value; }

  // ---- line searches along d, starting from step a ------------------------
  var MU1 = 1e-4, RHO = 0.5;                                        // Armijo (mdobook Alg. 4.2 notation)
  function armijo(F, x, g, d, a) {
    var f0 = F.f(x[0], x[1]), slope = g[0] * d[0] + g[1] * d[1];
    if (!(slope < 0)) return 0;                                      // not a descent direction
    for (var i = 0; i < 60; i++) {
      if (F.f(x[0] + a * d[0], x[1] + a * d[1]) <= f0 + MU1 * a * slope) return a;
      a *= RHO;
    }
    return 0;
  }
  function exact(F, x, g, d, a) {                                   // bracket by doubling, then golden section
    function phi(t) { return F.f(x[0] + t * d[0], x[1] + t * d[1]); }
    var f0 = phi(0), b = a, fb = phi(b), i;
    for (i = 0; i < 60 && !(fb < f0); i++) { b *= 0.5; fb = phi(b); }
    if (!(fb < f0)) return 0;
    var lo = 0, c = 2 * b, fc = phi(c);
    for (i = 0; i < 80 && fc < fb; i++) { lo = b; b = c; fb = fc; c *= 2; fc = phi(c); }
    var R = (Math.sqrt(5) - 1) / 2, hi = c;
    var x1 = hi - R * (hi - lo), x2 = lo + R * (hi - lo), f1 = phi(x1), f2 = phi(x2);
    for (i = 0; i < 60; i++) {
      if (f1 < f2) { hi = x2; x2 = x1; f2 = f1; x1 = hi - R * (hi - lo); f1 = phi(x1); }
      else         { lo = x1; x1 = x2; f1 = f2; x2 = lo + R * (hi - lo); f2 = phi(x2); }
    }
    return 0.5 * (lo + hi);
  }

  // ---- the three methods; each returns [{x, y, d, alpha}] -----------------
  function newtonDir(F, x, g) {
    var H = F.h(x[0], x[1]), det = H[0] * H[2] - H[1] * H[1];
    if (!(Math.abs(det) > 1e-14)) return [-g[0], -g[1]];
    return [-( H[2] * g[0] - H[1] * g[1]) / det, -(-H[1] * g[0] + H[0] * g[1]) / det];
  }
  function run(F, method, x0, alpha, ls, n) {                        // ls: 'fixed' | 'exact' | 'armijo'
    var x = x0.slice(), g = F.g(x[0], x[1]), d = [-g[0], -g[1]], gprev = null, dprev = null;
    var pts = [{ x: x[0], y: x[1] }], status = '', fallback = false;
    for (var k = 0; k < n; k++) {
      var gn = Math.hypot(g[0], g[1]);
      if (gn < 1e-9) { status = 'converged'; break; }
      if (method === 'sd') d = [-g[0], -g[1]];
      else if (method === 'cg') {
        if (gprev) {
          var beta = Math.max(0, (g[0] * (g[0] - gprev[0]) + g[1] * (g[1] - gprev[1])) / (gprev[0] * gprev[0] + gprev[1] * gprev[1]));
          d = [-g[0] + beta * dprev[0], -g[1] + beta * dprev[1]];
          if (d[0] * g[0] + d[1] * g[1] >= 0) d = [-g[0], -g[1]];   // restart if not a descent direction
        } else d = [-g[0], -g[1]];
      } else {
        d = newtonDir(F, x, g);
        if (ls !== 'fixed' && d[0] * g[0] + d[1] * g[1] >= 0) { d = [-g[0], -g[1]]; fallback = true; }   // not a descent direction
      }
      var a0 = method === 'nt' ? 1 : alpha;                           // Newton's natural step is 1
      var a = ls === 'exact' ? exact(F, x, g, d, a0) : ls === 'armijo' ? armijo(F, x, g, d, a0) : a0;
      pts[pts.length - 1].d = d; pts[pts.length - 1].alpha = a; pts[pts.length - 1].fallback = fallback; fallback = false;
      x = [x[0] + a * d[0], x[1] + a * d[1]];
      if (!isFinite(x[0]) || !isFinite(x[1]) || Math.abs(x[0]) > 1e6 || Math.abs(x[1]) > 1e6) { status = 'diverged'; break; }
      pts.push({ x: x[0], y: x[1] });
      gprev = g; dprev = d; g = F.g(x[0], x[1]);
      if (a === 0) { status = 'stuck (no descent along d)'; break; }
    }
    return { pts: pts, status: status };
  }

    return cache[key];
  }

  }

  <h2>1. What the Hessian looks like near a stationary point</h2>

  <p>Near a point where the gradient is zero, every smooth function looks
  like a quadratic built from its Hessian \(H\), the matrix of second
  derivatives:
  \[ f(x, y) \approx \tfrac{1}{2}
     \begin{bmatrix} x & y \end{bmatrix} H
     \begin{bmatrix} x \\ y \end{bmatrix}, \qquad
     H = \begin{bmatrix} \dfrac{\partial^2 f}{\partial x^2} & \dfrac{\partial^2 f}{\partial x\,\partial y} \\[1.1em]
         \dfrac{\partial^2 f}{\partial x\,\partial y} & \dfrac{\partial^2 f}{\partial y^2} \end{bmatrix}. \]
  The quadratic below is set up through the eigenvalues of \(H\), which are
  the curvatures along its two principal directions, and the angle of the
  first principal direction. The signs of the eigenvalues decide what kind
  of point the origin is.</p>

  <p>The dashed lines on the contour plot are the eigenvectors of \(H\).
  Along each one the function is a parabola with curvature equal to that
  eigenvalue. Both positive: a bowl, the origin is a minimum, \(H\) is
  positive definite. Both negative: a dome, a maximum, negative definite.
  One of each: a saddle, which is a maximum along one line and a minimum
  along the other, and \(H\) is indefinite. Without computing eigenvalues,
  the same test is
  \[ \det H = \frac{\partial^2 f}{\partial x^2}\,\frac{\partial^2 f}{\partial y^2}
     - \left(\frac{\partial^2 f}{\partial x\,\partial y}\right)^2 : \]
  a saddle has \(\det H < 0\), and when \(\det H > 0\) the sign of
  \(\partial^2 f / \partial x^2\) says
  whether it is a minimum or a maximum. The surface can be dragged to
  rotate it.</p>
  <h2>2. The function from the in-class assignment</h2>

  <p>The second exercise on the handout asked you to classify the stationary
  points of
  \[ f(x, y) = \frac{x^3}{3} - x + \frac{y^3}{3} - y \]
  from its contour plot alone. Here is the same function as a surface
  (drag to rotate it), with the four kinds of point from part 1 in one place. Its gradient and Hessian are
  \[ \nabla f = \begin{bmatrix} x^2 - 1 \\ y^2 - 1 \end{bmatrix}, \qquad
     H = \begin{bmatrix} 2x & 0 \\ 0 & 2y \end{bmatrix}, \]
  so the first-order necessary condition \(\nabla f = 0\) holds at exactly
  four points, \((\pm 1, \pm 1)\). Pick one to see its Hessian.</p>

  <p>Because the Hessian here happens to be diagonal, its eigenvalues are just
  the diagonal entries \(2x\) and \(2y\). At \((1,1)\) both are positive, so
  \(H\) is positive definite and the point is a local minimum (a bowl). At
  \((-1,-1)\) both are negative: a local maximum (a dome). At the other two
  the signs differ, so \(H\) is indefinite and the surface is a saddle, curving
  up along one axis and down along the other. Notice that \((1,1)\) is only a
  <em>local</em> minimum: \(f\) keeps decreasing toward the corner of the
  plotted region, and it is unbounded below.</p>

<script>
(function () {
  function $(id) { return document.getElementById(id); }
  function fmt(v, d) { return isFinite(v) ? v.toFixed(d) : 'NaN'; }
  function grid(n, lim) {
    var g = [];
    for (var i = 0; i < n; i++) g.push(-lim + 2 * lim * i / (n - 1));
    return g;
  }
  var COL = { 'op-min': '#2a7a3b', 'op-max': '#c02a2a', 'op-sad': '#7b3fa0', 'op-deg': '#777' };
  var PLOTOPTS = { displayModeBar: false, responsive: true };

  // Classify a symmetric 2x2 Hessian by its eigenvalues. `who` names the point
  // ("" or "the origin is ") so the same text works in both sections.
  function classify(l1, l2, who) {
    var eps = 1e-9, c;
    if (l1 > eps && l2 > eps)        c = { cls: 'op-min', txt: 'positive definite: ' + who + 'a local minimum (a bowl)' };
    else if (l1 < -eps && l2 < -eps) c = { cls: 'op-max', txt: 'negative definite: ' + who + 'a local maximum (a dome)' };
    else if (l1 * l2 < -eps)         c = { cls: 'op-sad', txt: 'indefinite: ' + who + 'a saddle point' };
    else                             c = { cls: 'op-deg', txt: 'singular (an eigenvalue is zero): a flat direction, the test is inconclusive' };
    return c;
  }

  // Draw a surface, keeping the user's camera if the plot already exists.
  function surfacePlot(id, traces, layout, eye) {
    var div = $(id);
    if (div.layout && div.layout.scene) {
      layout.scene.camera = div.layout.scene.camera;
      Plotly.react(id, traces, layout, PLOTOPTS);
    } else {
      layout.scene.camera = { eye: eye };
      Plotly.newPlot(id, traces, layout, PLOTOPTS);
    }
  }

  // ---- part 1: quadratic landscape ----------------------------------------
  var LIM = 2, xs = grid(41, LIM), ys = xs;

  function hessian() {
    var l1 = +$('op-l1').value, l2 = +$('op-l2').value, th = +$('op-th').value * Math.PI / 180;
    var c = Math.cos(th), s = Math.sin(th);
    // H = R diag(l1, l2) R^T with R = [c -s; s c]
    return { l1: l1, l2: l2, th: th,
             a: l1 * c * c + l2 * s * s, b: (l1 - l2) * c * s, d: l1 * s * s + l2 * c * c };
  }
  function drawQuad() {
    var H = hessian();
    $('op-l1v').textContent = fmt(H.l1, 1);
    $('op-l2v').textContent = fmt(H.l2, 1);
    $('op-thv').textContent = Math.round(H.th * 180 / Math.PI);
    $('op-h11').textContent = fmt(H.a, 2); $('op-h12').textContent = fmt(H.b, 2);
    $('op-h21').textContent = fmt(H.b, 2); $('op-h22').textContent = fmt(H.d, 2);
    var det = H.a * H.d - H.b * H.b, c = classify(H.l1, H.l2, 'the origin is ');
    $('op-defn').innerHTML = 'λ₁ = ' + fmt(H.l1, 1) + ', λ₂ = ' + fmt(H.l2, 1) + ' — <span class="' + c.cls + '">' + c.txt + '</span>';
    $('op-dettr').textContent = 'det H = ' + fmt(det, 2) + ' = λ₁λ₂,   H₁₁ = ' + fmt(H.a, 2);

    var z = ys.map(function (y) {
      return xs.map(function (x) { return 0.5 * (H.a * x * x + 2 * H.b * x * y + H.d * y * y); });
    });
    var zmax = 0.5 * Math.max(Math.abs(H.l1), Math.abs(H.l2), 0.5) * 2 * LIM * LIM;
    var zr = [-zmax, zmax];

    // eigenvector lines on the contour plot
    var cth = Math.cos(H.th), sth = Math.sin(H.th), L = LIM * 1.5;
    var eig = [[[-L * cth, L * cth], [-L * sth, L * sth]], [[L * sth, -L * sth], [-L * cth, L * cth]]];
    var contour = [{
      type: 'contour', x: xs, y: ys, z: z, colorscale: 'RdBu', reversescale: true,
      zmin: zr[0], zmax: zr[1], ncontours: 24, line: { width: 1 },
      contours: { showlabels: false }, showscale: false, hovertemplate: 'x %{x:.2f}, y %{y:.2f}<br>f %{z:.2f}<extra></extra>'
    }];
    eig.forEach(function (e, i) {
      contour.push({ type: 'scatter', mode: 'lines', x: e[0], y: e[1], showlegend: false, hoverinfo: 'skip',
                     line: { color: '#333', width: 1.5, dash: 'dash' } });
      contour.push({ type: 'scatter', mode: 'text', x: [e[0][1] * 0.6], y: [e[1][1] * 0.6],
                     text: ['λ' + (i ? '₂' : '₁') + ' = ' + fmt(i ? H.l2 : H.l1, 1)], textposition: 'top center',
                     textfont: { size: 14, color: '#222' }, showlegend: false, hoverinfo: 'skip' });
    });
    var clayout = { margin: { l: 40, r: 10, t: 10, b: 40 }, xaxis: { title: 'x', range: [-LIM, LIM], scaleanchor: 'y' },
                    yaxis: { title: 'y', range: [-LIM, LIM] }, paper_bgcolor: 'rgba(0,0,0,0)' };
    Plotly.react('op-contour', contour, clayout, PLOTOPTS);

    var surface = [{ type: 'surface', x: xs, y: ys, z: z, colorscale: 'RdBu', reversescale: true,
                     cmin: zr[0], cmax: zr[1], showscale: false, opacity: 0.95,
                     contours: { z: { show: true, usecolormap: true, width: 1, project: { z: false } } },
                     hovertemplate: 'x %{x:.2f}, y %{y:.2f}<br>f %{z:.2f}<extra></extra>' }];
    var slayout = { margin: { l: 0, r: 0, t: 0, b: 0 }, paper_bgcolor: 'rgba(0,0,0,0)',
                    scene: { xaxis: { title: 'x', range: [-LIM, LIM] }, yaxis: { title: 'y', range: [-LIM, LIM] },
                             zaxis: { title: 'f', range: [-8.5, 8.5] }, aspectmode: 'cube' } };
    surfacePlot('op-surface', surface, slayout, { x: 1.6, y: -1.6, z: 0.9 });
  }
  ['op-l1', 'op-l2', 'op-th'].forEach(function (id) { $(id).addEventListener('input', drawQuad); });
  drawQuad();

  // ---- part 2: the handout function ----------------------------------------
  var FL = 2.5, fxs = grid(61, FL), fys = fxs;
  function F(x, y) { return x * x * x / 3 - x + y * y * y / 3 - y; }
  var fz = fys.map(function (y) { return fxs.map(function (x) { return F(x, y); }); });
  var SP = [[1, 1], [-1, -1], [1, -1], [-1, 1]];

  function drawF() {
    var sel = document.querySelector('input[name=op-sp]:checked').value.split(',').map(Number);
    var a = 2 * sel[0], d = 2 * sel[1];   // H = diag(2x, 2y)
    var c = classify(a, d, '');
    $('op-s11').textContent = fmt(a, 0); $('op-s12').textContent = '0';
    $('op-s21').textContent = '0';       $('op-s22').textContent = fmt(d, 0);
    $('op-sdefn').innerHTML = 'λ₁ = ' + fmt(a, 0) + ', λ₂ = ' + fmt(d, 0) + ' — <span class="' + c.cls + '">' + c.txt + '</span>';
    $('op-sdettr').textContent = 'at (' + sel[0] + ', ' + sel[1] + '):  f = ' + fmt(F(sel[0], sel[1]), 2) +
                                 ',  det H = ' + fmt(a * d, 0) + ',  H₁₁ = ' + fmt(a, 0);

    var cols = SP.map(function (p) { return COL[classify(2 * p[0], 2 * p[1], '').cls]; });
    var lines = SP.map(function (p) { return (p[0] === sel[0] && p[1] === sel[1]) ? 3 : 0; });
    var hover = 'x %{x:.2f}, y %{y:.2f}<br>f %{z:.2f}<extra></extra>';

    var contour = [
      { type: 'contour', x: fxs, y: fys, z: fz, colorscale: 'RdBu', reversescale: true,
        zmin: -5.5, zmax: 5.5, contours: { start: -5, end: 5, size: 0.5, showlabels: true,
        labelfont: { size: 9, color: '#222' } }, line: { width: 1 }, showscale: false, hovertemplate: hover },
      { type: 'scatter', mode: 'markers', x: SP.map(function (p) { return p[0]; }), y: SP.map(function (p) { return p[1]; }),
        marker: { size: 12, color: cols, line: { color: '#222', width: lines } }, hoverinfo: 'skip', showlegend: false }
    ];
    var clayout = { margin: { l: 40, r: 10, t: 10, b: 40 }, paper_bgcolor: 'rgba(0,0,0,0)',
                    xaxis: { title: 'x', range: [-FL, FL], scaleanchor: 'y', dtick: 1 },
                    yaxis: { title: 'y', range: [-FL, FL], dtick: 1 } };
    Plotly.react('op-fcontour', contour, clayout, PLOTOPTS);

    var surface = [
      { type: 'surface', x: fxs, y: fys, z: fz, colorscale: 'RdBu', reversescale: true,
        cmin: -5.5, cmax: 5.5, showscale: false, opacity: 0.95,
        contours: { z: { show: true, usecolormap: true, width: 1, project: { z: false } } }, hovertemplate: hover },
      { type: 'scatter3d', mode: 'markers', x: SP.map(function (p) { return p[0]; }), y: SP.map(function (p) { return p[1]; }),
        z: SP.map(function (p) { return F(p[0], p[1]) + 0.03; }),
        marker: { size: 6, color: cols, line: { color: '#222', width: lines } }, hoverinfo: 'skip', showlegend: false },
      // a thin vertical stem under the selected point so it is easy to find on the surface
      { type: 'scatter3d', mode: 'lines', x: [sel[0], sel[0]], y: [sel[1], sel[1]], z: [-6, F(sel[0], sel[1])],
        line: { color: COL[c.cls], width: 4, dash: 'dash' }, hoverinfo: 'skip', showlegend: false }
    ];
    var slayout = { margin: { l: 0, r: 0, t: 0, b: 0 }, paper_bgcolor: 'rgba(0,0,0,0)',
                    scene: { xaxis: { title: 'x', range: [-FL, FL] }, yaxis: { title: 'y', range: [-FL, FL] },
                             zaxis: { title: 'f', range: [-6, 6] }, aspectmode: 'cube' } };
    surfacePlot('op-fsurface', surface, slayout, { x: 1.5, y: -1.7, z: 0.8 });
  }
  Array.prototype.forEach.call(document.querySelectorAll('input[name=op-sp]'),
                               function (r) { r.addEventListener('change', drawF); });
  drawF();
})();

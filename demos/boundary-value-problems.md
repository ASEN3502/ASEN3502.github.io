  <h2>1. Initial value vs. boundary value</h2>

  <p>A lightly damped mass on a spring:
  \[ \ddot{x} = -\omega^2 x - c\,\dot{x}, \qquad \omega = 2,\quad c = 0.2,\quad 0 \le t \le T = 4. \]
  A second-order equation needs two conditions to pin down a solution.
  <em>Where</em> those conditions are given changes the problem completely.</p>

  <p>Every ODE solver we have (Euler, RK4, <code>ode45</code>) starts from a full
  state and steps forward. For the boundary value problem we must somehow
  find the missing initial slope, or give up on marching altogether and
  solve for all the points at once. Those are the two strategies below.</p>

  <h2>2. A heated rod</h2>

  <p>A thin rod of length \(L = 10\) is held at \(T(0) = 40\) at one end and
  \(T(L) = 200\) at the other, in surroundings at \(T_\infty = 20\). Heat
  conducts along the rod and leaves its surface by convection and radiation:
  \[ \frac{d^2 T}{dx^2} = h'\,(T - T_\infty) + \sigma''\,(T^4 - T_\infty^4),
     \qquad T(0) = 40,\quad T(L) = 200. \]
  The \(T^4\) term makes the equation nonlinear. Set \(\sigma'' = 0\) to see
  what changes when the problem is linear.</p>

  <h3>Shooting method</h3>

  <details class="bv-fold">
  <summary>How to shoot</summary>
  <p>Guess the missing slope \(z = T'(0)\), integrate the IVP with RK4 out
  to \(x = L\), and look at how far \(T(L)\) lands from 200.  That makes
  a root-finding problem, \(g(z) = T(L; z) - 200 = 0\), in the single
  unknown \(z\).  Each new guess comes from the secant method through the
  previous two:
  \[ z_{k+1} = z_k - g(z_k)\,\frac{z_k - z_{k-1}}{g(z_k) - g(z_{k-1})}. \]</p>

  <h3>Finite differences</h3>

  <p>Instead of marching, split the rod into \(n\) segments of width
  \(\Delta x = L/n\) and replace the derivative at every interior node by a
  centered difference:
  \[ \frac{T_{i-1} - 2T_i + T_{i+1}}{\Delta x^2}
     = h'\,(T_i - T_\infty) + \sigma''\,(T_i^4 - T_\infty^4),
     \qquad i = 1, \dots, n-1. \]
  With \(T_0 = 40\) and \(T_n = 200\) known, this is \(n - 1\) equations in
  \(n - 1\) unknowns, all coupled to their neighbors.  Because of the
  \(T_i^4\) term the system is nonlinear, so it is solved with
  Newton-Raphson; the Jacobian is tridiagonal.</p>

  // ====== Part 2: heated rod ==================================================
  var L = 10, TA = 20, T0 = 40, TL = 200;
  var HP = [0, 0.005, 0.01, 0.02, 0.05], SP = [0, 1e-9, 2.7e-9, 5e-9, 1e-8];
  var SPLBL = ['0', '1 × 10⁻⁹', '2.7 × 10⁻⁹', '5 × 10⁻⁹', '1 × 10⁻⁸'];
  var hp, sp;
  function rod(x, s) {
    var T = s[0];
    return [s[1], hp * (T - TA) + sp * (T * T * T * T - TA * TA * TA * TA)];
  }
  function endT(sol) { return sol[sol.length - 1][1][0]; }

  // Secant iteration on g(z) = T(L; z) - TL.  Returns the list of shots.
  // A shot that blows up (T^4 runs away) is retried halfway back toward the
  // last good guess; the secant step always uses the last two good shots.
  function shootHistory(z0, z1, N, tol, maxit) {
    var hist = [], good = [];
    function shot(z) {
      var s = rk4(rod, [T0, z], 0, L, N), h = { z: z, sol: s, g: endT(s) - TL };
      hist.push(h);
      if (isFinite(h.g)) good.push(h);
      return h;
    }
    shot(z0); shot(z1);
    while (hist.length <= maxit) {
      if (good.length < 2) break;
      var a = good[good.length - 2], b = good[good.length - 1];
      if (Math.abs(b.g) < tol || b.g === a.g) break;
      var z = b.z - b.g * (b.z - a.z) / (b.g - a.g);
      if (!isFinite(z)) break;
      var h = shot(z), tries = 0;
      while (!isFinite(h.g) && tries++ < 4 && hist.length <= maxit) {
        z = (z + b.z) / 2;
        h = shot(z);
      }
      if (!isFinite(h.g)) break;
    }
    return hist;
  }

  // Finite differences with Newton-Raphson and a tridiagonal (Thomas) solve.
  function fdSolve(n) {
    var dx = L / n, m = n - 1, T = [], i, it;
    for (i = 1; i <= m; i++) T.push(T0 + (TL - T0) * i / n);
    var r = 1 / (dx * dx), TA4 = TA * TA * TA * TA;
    for (it = 1; it <= 50; it++) {
      var F = [], diag = [], cp = [], dp = [];
      for (i = 0; i < m; i++) {
        var Tl = i === 0 ? T0 : T[i - 1], Tr = i === m - 1 ? TL : T[i + 1], Ti = T[i];
        F.push(r * (Tl - 2 * Ti + Tr) - hp * (Ti - TA) - sp * (Ti * Ti * Ti * Ti - TA4));
        diag.push(-2 * r - hp - 4 * sp * Ti * Ti * Ti);
      }
      // Solve J d = -F; sub- and super-diagonals are both r.
      cp[0] = r / diag[0]; dp[0] = -F[0] / diag[0];
      for (i = 1; i < m; i++) {
        var den = diag[i] - r * cp[i - 1];
        cp[i] = r / den; dp[i] = (-F[i] - r * dp[i - 1]) / den;
      }
      var d = new Array(m), big = 0;
      d[m - 1] = dp[m - 1];
      for (i = m - 2; i >= 0; i--) d[i] = dp[i] - cp[i] * d[i + 1];
      for (i = 0; i < m; i++) { T[i] += d[i]; big = Math.max(big, Math.abs(d[i])); }
      if (big < 1e-9) break;
    }
    var xs = [0], Ts = [T0];
    for (i = 0; i < m; i++) { xs.push((i + 1) * dx); Ts.push(T[i]); }
    xs.push(L); Ts.push(TL);
    return { x: xs, T: Ts, iters: it, dx: dx };
  }

  // Round y range outward to a nice step; returns {ymin, ymax, ystep}.
  function niceRange(lo, hi) {
    var steps = [10, 20, 25, 50, 100, 200, 250, 500, 1000], st = steps[steps.length - 1];
    for (var i = 0; i < steps.length; i++) if ((hi - lo) / steps[i] <= 9) { st = steps[i]; break; }
    return { ymin: Math.floor(lo / st) * st, ymax: Math.ceil(hi / st) * st, ystep: st };
  }

  function solveShooting() {
    var z0 = +z0In.value, z1 = +z1In.value;
    $('bv-z0v').textContent = z0; $('bv-z1v').textContent = z1;
    // The slider always runs 0..KMAX so it does not jump around as the

  }

      });
    });
    var r = niceRange(Math.max(lo, -500), Math.min(hi, 1000));

    // Zoomed view of the last half unit of the rod, around the target.

  function el2(n) { return document.createElement(n); }

  function solveFD() {
    ref = fdSolve(NREF);
    fdAll = NS_FD.map(function (n) {
      var s = fdSolve(n), err = 0, stride = NREF / n;
      for (var i = 0; i <= n; i++) err = Math.max(err, Math.abs(s.T[i] - ref.T[i * stride]));
      s.err = err; s.n = n;
      return s;
    });
  }
